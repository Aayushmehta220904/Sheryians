# Componentra — React Component Library

Componentra is an enhanced React + TypeScript component library and documentation workspace built by improving and completing the provided starter codebase. It includes reusable primitives, production-ready Tooltip behavior, Carousel and Layout components, responsive navigation, templates, theme-aware documentation previews, and component API references.


Enhanced by **Aayush Mehta**.

The documentation search supports **Ctrl/Cmd + K** for quick component discovery.

## Included components

- Button
- Card
- Modal
- Input
- Navbar
- Carousel
- Tooltip
- Layout

## Tooltip features

- Top, right, bottom and left placement
- Viewport collision handling
- Multiple visual variants and sizes
- Configurable open/close delay and offset
- Arrow support
- Interactive mode
- Controlled and uncontrolled state
- Hover and keyboard focus activation
- Escape-to-close behavior
- Portal rendering
- Repositioning on scroll and resize

## Additional completion work

- Fully implemented Carousel component and documentation
- Fully implemented Layout component and documentation
- Theme-aware component preview windows
- Theme-aware API tables and code previews
- Working About route
- Working Templates route
- Working Components overview route
- Functional component search in the top navigation
- Functional mobile navigation
- Persistent light/dark theme
- SPA routing configuration for Vercel

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Build the reusable library bundle

```bash
npm run build:lib
```
