# Productivity Dashboard

A modern single-page Productivity Dashboard built using **HTML, CSS, and Vanilla JavaScript**. The application combines multiple productivity tools into one dashboard, allowing users to organize daily work, manage tasks, stay motivated, monitor weather, and improve focus without using any backend or database.

---

## Project Overview

The dashboard is designed as a **Single Page Application (SPA)** where users navigate between features without reloading the page.

The project focuses on practicing:

- DOM Manipulation
- Event Handling
- Local Storage
- Fetch API
- Date Object
- Timers (`setInterval`)
- Responsive Design
- CSS Variables
- Dynamic UI Rendering

---

## Features

### Dashboard Navigation
- Interactive dashboard with feature cards
- Open one feature at a time
- Back button returns to dashboard
- No page reloads

### Todo List
- Add tasks
- Mark task as important
- Mark task as completed
- Delete task
- Event delegation
- Local Storage support

### Daily Planner
- Hourly planner
- Save notes for each time slot
- Edit existing entries
- Local Storage persistence

### Motivation Quotes
- Fetches inspirational quotes using Fetch API
- Loading indicator
- Error handling
- Fallback quote support

### Pomodoro Timer
- 25-minute work timer
- Start
- Pause
- Reset
- Countdown display
- Prevents multiple running intervals

### Weather Widget
- Current weather
- Temperature
- Weather condition
- Humidity
- Wind speed
- Feels Like
- Supports geolocation and city search

### Date & Time
- Live clock
- Current date
- Updates automatically every second

### Dynamic Background
- Background changes according to time of day
- Morning
- Afternoon
- Evening
- Night

### Theme Switch
- Light Mode
- Dark Mode
- Theme preference saved using Local Storage

### Daily Goals
- Add goals
- Complete goals
- Delete goals
- Progress counter
- Local Storage support
