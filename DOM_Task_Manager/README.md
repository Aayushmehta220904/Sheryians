# DOM Explorer: Interactive Task Manager Using Pure JavaScript

This project is a complete interactive Task Manager Application built using only HTML, CSS, and Vanilla JavaScript.

No frameworks or JavaScript libraries are used.

## Features

- Add task
- Edit task
- Complete / undo task
- Delete task
- Duplicate task
- Search task
- Filter by category
- Completed task counter
- Pending task counter
- Clear all tasks
- Dark mode / light mode
- Local Storage integration
- Event Delegation
- Event Bubbling and Event Capturing demo
- Browser Rendering Pipeline visual section

## DOM Manipulation

The project uses:

- createElement()
- createTextNode()
- append()
- appendChild()
- prepend()
- before()
- after()
- replaceWith()
- remove()
- DocumentFragment
