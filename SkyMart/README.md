# SkyMart

SkyMart is an original React e-commerce frontend built from a visual and functional brief. It includes authentication, protected routes, a product catalogue, filtering, sorting, product details, cart, wishlist, persistent Local Storage state, responsive design and Vercel SPA routing.

## Features
- Login and signup with validation
- Demo login: `demo@skymart.in` / `demo123`
- Protected application routes
- Product data from DummyJSON
- Search, category filters and sorting
- Product details with image gallery and quantity selector
- Cart quantity update, removal and order summary
- Wishlist
- Local Storage persistence
- Responsive navigation and layouts
- INR price formatting

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
